Privacy policy

Last updated: 2026-10-18.

This tool (gcalcli) runs entirely on the device of the single person who authorizes it. It requests read-only access to that person's own Google Calendar (calendar.readonly scope) in order to display events in a terminal.

  • No calendar data is sent to, stored on, or processed by any server other than Google's own Calendar API and the local machine running the tool.
  • No data is shared with any third party.
  • No data is used for advertising, analytics, or any purpose other than displaying your own calendar to you.
  • The OAuth refresh token is stored locally on the authorizing user's own machine (~/.local/share/gcalcli/) and nowhere else.

Access can be revoked at any time at myaccount.google.com/permissions.

Contact: see the GitHub account hosting this page.
