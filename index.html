gcalcli (personal tool)

This page exists only to satisfy Google's OAuth consent screen requirements for a personal command-line tool. It is not a product, service, or company.

What it is: gcalcli is an open-source command-line client (github.com/insanum/gcalcli) that one person (the owner of this GitHub account) runs locally to read their own Google Calendar from a terminal. It is not distributed to, or used by, anyone else.

See the privacy policy for how calendar data is (and is not) handled.
